# Trae DocxAgent 写作指令（论文强化版）

## 1. 使用目标

将现有论文草稿重写为“可提交的高质量毕业论文文本”，严格对齐章节模板与学术表达规范。

## 2. 输入材料

1. 章节模板：`docs/毕业论文辅助文档.md`（重点参考“7.3 论文结构建议”）
2. 当前正文：`data/academic_report_20260301_010319.md`
3. 技术说明：`docs/TECHNICAL_ARCHITECTURE.md`
4. 创新点素材：`docs/论文创新点与技术亮点.md`

## 3. 必须遵守的硬性要求

1. 章节结构必须为：摘要、1-9章、参考文献、附录。
2. 术语前后一致：情感倾向、CSI满意度指数、紧急度、方面级情感分析。
3. 数据口径一致：平台数量、样本量、时间范围不能互相冲突。
4. 禁止口语化与营销化表达，使用学术书面语。
5. 每章末尾必须有“本章小结”。
6. 第8章必须包含：实验设置、评价指标、对比实验、误差分析。
7. 参考文献需与正文引用对应，采用统一编号样式 `[1] [2] ...`。

## 4. 让论文“优秀”的增强动作

1. 增加问题导向叙事：每章开头先说“要解决什么问题”。
2. 增加方法细节：
   - 混合策略切换条件（长文本阈值、深度分析比例）
   - CSI计算公式与变量解释
   - 紧急度评分规则
3. 增加可复现实验描述：
   - 环境（Python版本、依赖、硬件）
   - 数据流程（采集、清洗、去重、分析）
4. 增加对比与消融：
   - SnowNLP vs DeepSeek vs 混合策略
   - 去掉方面分析/去掉深度分析后的性能变化
5. 增加局限性与威胁分析：
   - 样本偏差、平台偏差、时间窗口偏差
   - API稳定性与成本约束

## 5. 直接可用的 DocxAgent 指令

```text
你是一名中文计算机类毕业论文写作助手。请基于以下文件重写论文正文：
- 模板：docs/毕业论文辅助文档.md
- 草稿：data/academic_report_20260301_010319.md
- 技术材料：docs/TECHNICAL_ARCHITECTURE.md、docs/论文创新点与技术亮点.md

输出要求：
1) 严格按“摘要 + 第1章~第9章 + 参考文献 + 附录”组织；
2) 语言为学术中文，避免口语、夸张词；
3) 所有数据口径一致（平台、样本、时间范围）；
4) 每章包含“问题-方法-结果-小结”；
5) 第8章包含可复现实验细节、对比实验、消融实验、误差分析；
6) 给出图表插入建议（图x-x、表x-x）与每个图表一句话解读；
7) 产出可直接粘贴到论文模板中的正文文本，不输出额外解释。
```

## 6. 交付检查清单（用于验收）

1. 是否存在章节缺失或顺序错误。
2. 是否出现“平台数量前后不一致”。
3. 是否出现“结论先行但无实验支撑”。
4. 是否每章都有小结。
5. 是否存在未在参考文献中出现的正文引用。
